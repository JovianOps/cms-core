# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.0   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities by opening a private security advisory on GitHub.

[GitHub Security Advisory](https://github.com/JovianOps/cms-core/security/advisories/new)

We will acknowledge receipt and provide a fix within 72 hours.
