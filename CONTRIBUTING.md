# Contributing to cms-core

## Development Setup

```bash
git clone https://github.com/JovianOps/cms-core.git
cd cms-core
pip install -e ".[dev]"
```

## Running Tests

```bash
pytest tests/
```

## Contributing

1. Fork the repo
2. Create a feature branch (`git checkout -b feat/x`)
3. Commit your changes (`git commit -m "feat: ..."`)
4. Push (`git push origin feat/x`)
5. Open a PR

All PRs require passing tests.
